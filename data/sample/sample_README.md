# Sample Data

This folder contains a **small sample** (2 companies × 5 years = 10 rows) of the full
panel dataset, provided only to demonstrate the data schema and format.

The full dataset (20 companies, 2020–2024, 38 variables) is not published in this
repository due to data usage restrictions on the source material. It is available upon
request for academic/verification purposes.

See `sample_panel_data.csv` for the schema — column names and structure match the full
dataset exactly.
